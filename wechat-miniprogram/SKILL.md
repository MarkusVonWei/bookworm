# 微信小程序发布流程

微信小程序的开发、测试、审核与发布完整流程指南。

## 快速开始

### 前置条件

1. 注册微信公众平台账号：https://mp.weixin.qq.com/
2. 安装微信开发者工具：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
3. 准备企业营业执照（个人号功能受限）

### 核心流程

```
注册账号 → 安装工具 → 开发调试 → 上传代码 → 提交审核 → 发布上线
```

## 详细步骤

### 1. 注册小程序账号

1. 访问 https://mp.weixin.qq.com/ 点击「立即注册」
2. 选择「小程序」类型
3. 填写邮箱、密码等信息
4. 完成邮箱验证
5. 选择主体类型（个人/企业/政府/媒体）
6. 完成主体信息登记

> **注意**：个人主体小程序无法使用微信支付、卡券等高级能力

### 2. 获取 AppID

1. 登录微信公众平台
2. 进入「开发」→「开发管理」→「开发设置」
3. 复制 AppID（小程序ID）

### 3. 安装开发工具

1. 下载安装微信开发者工具
2. 使用管理员微信扫码登录
3. 选择「小程序项目」
4. 填写项目名称、AppID、项目目录

### 4. 开发与调试

#### 项目结构
```
miniprogram/
├── app.js          # 小程序逻辑
├── app.json        # 小程序配置
├── app.wxss        # 全局样式
├── pages/          # 页面目录
│   ├── index/
│   │   ├── index.js
│   │   ├── index.json
│   │   ├── index.wxml
│   │   └── index.wxss
│   └── ...
├── utils/          # 工具函数
└── project.config.json  # 项目配置
```

#### 开发规范
- 使用 WXML 模板（类 HTML）
- 使用 WXSS 样式（类 CSS）
- 使用 JS 逻辑（注意：不能使用 DOM API）
- 配置 app.json 设置页面路由和窗口样式

### 5. 上传代码

1. 在开发者工具中点击「上传」
2. 填写版本号（如 1.0.0）
3. 填写项目备注
4. 点击「上传」

上传后代码会进入「版本管理」页面。

### 6. 提交审核

1. 登录微信公众平台
2. 进入「管理」→「版本管理」
3. 在「开发版本」中找到刚上传的版本
4. 点击「提交审核」
5. 填写审核信息：
   - 配置功能页面
   - 选择服务类目
   - 填写测试账号（如需要登录）
   - 补充说明材料
6. 等待审核（通常 1-7 个工作日）

### 7. 发布上线

1. 审核通过后，进入「版本管理」
2. 在「审核版本」中点击「全量发布」
3. 小程序正式上线

## 常见审核问题

### 被拒常见原因

1. **内容违规**：涉及政治、色情、赌博等敏感内容
2. **功能不完整**：页面空白、功能不可用
3. **隐私问题**：未配置隐私协议或过度收集用户信息
4. **类目不符**：服务类目与实际功能不匹配
5. **诱导分享**：强制用户分享才能使用功能

### 审核加速技巧

1. 确保所有页面都有实际内容
2. 配置完整的隐私保护指引
3. 选择准确的服务类目
4. 提供完整的测试说明
5. 避免使用敏感词汇

## 微信小程序限制

### 代码包限制

- 单个代码包最大 2MB
- 整个项目最大 20MB（含分包）
- 可使用分包加载突破单包限制

### API 限制

- 网络请求：最多同时 10 个
- 本地存储：单个 key 最大 1MB，总容量 10MB
- 文件上传：最大 10MB
- WebSocket：最多同时 1 个连接

### 审核周期

- 普通审核：1-7 个工作日
- 加急审核：2 小时内（需付费）
